# agent2026-campus-event-hub

> 校园活动信息聚合助手 — 天津大学 AI 智能体大赛 2026 参赛作品

## 一句话介绍

聚合天大各微信公众号发布的**讲座（含讲座单）**、**文体活动**、**志愿招募**信息，利用大模型自动提取结构化活动数据，集中展示在一个网页上。

## 解决什么问题

全校活动信息分散在十多个公众号里（学生会、各学院、社团、志愿者协会…），学生经常漏掉重要讲座和活动。特别是：

- **讲座单**：毕业需要 6 张人文学术讲座单（必修），很多学生不知道哪些讲座发单
- **活动**：歌手大赛、晚会、展览等，信息分散
- **志愿招募**：志愿者协会的招募信息很难被注意到

## 核心功能

| 功能 | 说明 |
|------|------|
| 📚 讲座聚合 | 自动提取讲座信息，标注**人文学术（必修）** / **主题教育（选修）** |
| 🎭 活动聚合 | 歌手大赛、晚会、展览、运动会等 |
| 🤝 志愿招募 | 志愿活动招募，标注志愿时长和报名截止 |
| 🔍 多维筛选 | 按类别、校区（卫津路/北洋园/线上）、讲座单类型筛选 |
| 🔄 自动更新 | 定时拉取公众号新文章，AI 自动解析 |
| 📱 移动适配 | 手机可访问，微信内直接打开 |

## 技术方案

```
公众号文章 → wechatDownload 采集 → TJU AI API 提取结构化信息 → SQLite 存储 → 前端网页展示
```

详见 [DESIGN.md](DESIGN.md)
