## 关键问题

### business_id 切换是否稳定
- **机制本身稳定**：前 8 个连续成功，验证了剪贴板驱动切换可行
- **但受密钥流程干扰**：一旦某个切换触发「开始获取密钥」（且未微信确认），工具进入不稳定状态，剪贴板监听**间歇性失效**，后续切换失败

### 失败根因
日志确认：`开始获取密钥` 出现 2 次，`获取密钥成功` 0 次。
- 18:38:53 工具重启后第一次切换触发密钥获取
- 密钥未在微信确认 → 工具停留在等待密钥状态 → 监听被干扰

### 密钥确认的必要性（硬性人工步骤）
- **密钥全局共享，只需微信确认一次**
- 确认后（日志出现「获取密钥成功」），密钥流程不再反复阻塞，切换应大幅稳定
- 这是微信强制步骤，无法自动化

### MCP 下载 / 下载完成检测 / 串号
